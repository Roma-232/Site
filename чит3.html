Ключевые моменты статьи

Декораторы — одна из самых мощных и элегантных особенностей Python. В этой статье мы разберем, как работают декораторы, научимся создавать свои собственные и применять их в реальных проектах.

Что такое декораторы?

Декораторы в Python — это функции, которые принимают другую функцию в качестве аргумента, добавляют к ней некоторую функциональность и возвращают модифицированную функцию. По сути, декораторы позволяют "обернуть" одну функцию другой, расширяя её поведение без изменения исходного кода.

Это реализация паттерна проектирования "Декоратор", который позволяет динамически добавлять новое поведение объектам. В Python декораторы широко используются для:

  • Логирования вызовов функций
  • Измерения времени выполнения
  • Кеширования результатов (мемоизация)
  • Проверки прав доступа
  • Валидации аргументов
  • Повторных попыток выполнения (retry)

Базовый синтаксис декораторов

Простейший декоратор — это функция, которая принимает функцию и возвращает функцию. Вот как это выглядит:

Пример 1: Простейший декоратор 

def simple_decorator(func):
    """Простой декоратор, который выводит сообщение при вызове функции"""
    def wrapper():
        print(f"Функция {func.__name__} была вызвана")
        return func()
    return wrapper

@simple_decorator
def say_hello():
    print("Привет, мир!")

# Теперь при вызове say_hello() будет выполняться обернутая версия
say_hello()
# Вывод:
# Функция say_hello была вызвана
# Привет, мир!

Важно

Символ @ — это синтаксический сахар в Python. Запись @simple_decorator перед определением функции эквивалентна say_hello = simple_decorator(say_hello).

Декораторы с аргументами

Часто нам нужно, чтобы декораторы принимали собственные аргументы. Для этого нужно создать функцию, которая возвращает декоратор:

Пример 2: Декоратор с аргументами 

def repeat(times):
    """Декоратор, который повторяет выполнение функции заданное количество раз"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for i in range(times):
                print(f"Попытка {i+1} из {times}")
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def greet(name):
    print(f"Привет, {name}!")
    return f"Приветствие отправлено для {name}"

result = greet("Анна")
print(f"Результат: {result}")

# Вывод:
# Попытка 1 из 3
# Привет, Анна!
# Попытка 2 из 3
# Привет, Анна!
# Попытка 3 из 3
# Привет, Анна!
# Результат: Приветствие отправлено для Анна

Практические примеры декораторов

1. Декоратор для измерения времени выполнения

Один из самых полезных декораторов в практике разработки:

Пример 3: Таймер выполнения 

import time
from functools import wraps

def timer(func):
    """Декоратор, измеряющий время выполнения функции"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.perf_counter()
        result = func(*args, **kwargs)
        end_time = time.perf_counter()
        elapsed_time = end_time - start_time
        print(f"Функция {func.__name__} выполнена за {elapsed_time:.4f} секунд")
        return result
    return wrapper

@timer
def calculate_factorial(n):
    """Вычисление факториала числа"""
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

# Использование
factorial_100 = calculate_factorial(100)
print(f"Факториал 100: {factorial_100}")

2. Декоратор для кеширования (мемоизация)

Идеально подходит для рекурсивных функций или вычислений с дорогими операциями:

Пример 4: Кеширующий декоратор 

from functools import wraps

def cache(func):
    """Декоратор для кеширования результатов функции"""
    cache_dict = {}
    
    @wraps(func)
    def wrapper(*args):
        if args in cache_dict:
            print(f"Возвращаем результат из кеша для {args}")
            return cache_dict[args]
        
        result = func(*args)
        cache_dict[args] = result
        print(f"Вычисляем и кешируем результат для {args}")
        return result
    
    return wrapper

@cache
def fibonacci(n):
    """Вычисление n-го числа Фибоначчи"""
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Использование
print(fibonacci(10))
print(fibonacci(10))  # Второй вызов использует кеш

Несколько декораторов для одной функции

В Python можно применять несколько декораторов к одной функции. Они применяются в порядке от ближайшего к функции к самому дальнему:

Пример 5: Несколько декораторов 

def decorator1(func):
    def wrapper():
        print("Декоратор 1: до вызова функции")
        result = func()
        print("Декоратор 1: после вызова функции")
        return result
    return wrapper

def decorator2(func):
    def wrapper():
        print("Декоратор 2: до вызова функции")
        result = func()
        print("Декоратор 2: после вызова функции")
        return result
    return wrapper

@decorator1
@decorator2
def say_hello():
    print("Привет из оригинальной функции!")

say_hello()

# Вывод:
# Декоратор 1: до вызова функции
# Декоратор 2: до вызова функции
# Привет из оригинальной функции!
# Декоратор 2: после вызова функции
# Декоратор 1: после вызова функции

Декораторы классов

Начиная с Python 3.7, появилась возможность использовать декораторы не только для функций, но и для классов:

Пример 6: Декоратор для класса 

def singleton(cls):
    """Декоратор, который превращает класс в Singleton"""
    instances = {}
    
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    
    return get_instance

@singleton
class DatabaseConnection:
    def __init__(self, connection_string):
        self.connection_string = connection_string
        self.connection = self.connect()
    
    def connect(self):
        print(f"Устанавливаем соединение с {self.connection_string}")
        return f"Соединение с {self.connection_string}"
    
    def query(self, sql):
        print(f"Выполняем запрос: {sql}")
        return "Результат запроса"

# Проверяем, что создается только один экземпляр
db1 = DatabaseConnection("postgresql://localhost/mydb")
db2 = DatabaseConnection("postgresql://localhost/mydb")

print(f"db1 is db2: {db1 is db2}")  # True - это один и тот же объект

Распространенные ошибки

При создании декораторов не забывайте использовать @wraps(func) из модуля functools. Это сохраняет метаданные оригинальной функции (имя, документацию), что важно для отладки и использования интроспекции.

Заключение

Декораторы — это мощный инструмент в арсенале Python-разработчика. Они позволяют писать чистый, повторно используемый код и реализовывать сквозную функциональность (cross-cutting concerns) без дублирования кода.

Освоив декораторы, вы сможете:

  • Создавать более модульный и поддерживаемый код
  • Реализовывать аспектно-ориентированное программирование в Python
  • Улучшать производительность с помощью кеширования
  • Добавлять логирование, мониторинг и отладку к существующему коду
  • Создавать выразительные API для своих библиотек

Начните с простых декораторов и постепенно переходите к более сложным конструкциям. Практикуйтесь, экспериментируйте, и вы быстро освоите этот элегантный инструмент Python!
